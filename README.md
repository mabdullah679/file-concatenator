# 📄 File Concatenator

A secure, high-performance, and **100% client-side** web application to merge PDFs, Images, and Text files into a single, professional PDF document.

---

## ✨ Features

- **🔐 Privacy First**: All processing happens locally in your browser. Your files are never uploaded to any server.
- **📁 Multi-Format Support**: Seamlessly combine PDFs, PNGs, JPGs, and TXT files.
- **📐 Smart Scaling**: Standardize your output to **Original size**, **A4**, or **US Letter**. Small images are centered, and large files are scaled down to fit perfectly.
- **🖱️ Intuitive UX**: Drag-and-drop interface with real-time file reordering and removal.
- **🎨 Premium Design**: A modern, glassmorphism-inspired interface that looks great on any device.

## 🛠️ Getting Started

### Prerequisites
- **Node.js** (v18.0 or higher)
- **npm** (comes with Node.js)

### Quick Start
1. **Clone the repo:**
   ```bash
   git clone https://github.com/your-username/file-concatenator.git
   cd file-concatenator
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Launch the development server:**
   ```bash
   npm run dev
   ```
4. **Visit:** `http://localhost:3000`

## 🚀 Deployment

This is a standard Next.js application. You can easily deploy it to **Vercel**, **Netlify**, or any static hosting provider.

```bash
npm run build
```
